## Назначение

Case Converter — расширение для Visual Studio Code, предназначенное для контекстной пакетной смены регистра переменных в активном редакторе. Плагин поддерживает преобразование между стилями `snake_case`, `camelCase` и `PascalCase`.

## Возможности

- Конвертация только в выделенном фрагменте текста. Перед открытием Quick Pick сохраняются `Selection` и вычисляется `baseOffset`, поэтому позиции найденных токенов корректно сопоставляются с исходным документом.
- Конвертация во всем активном документе, если выделение отсутствует.
- Безопасная фильтрация через Semantic Tokens API VS Code. Обрабатываются только токены типов `variable`, `parameter` и `property`; внешние вызовы функций и библиотечные идентификаторы не выбираются для замены.
- Атомарная замена через один вызов `editor.edit`. Токены сортируются справа налево, поэтому изменение длины одного имени не смещает позиции следующих замен.

## Поддерживаемые стили

| Стиль | Пример |
| --- | --- |
| `snake_case` | `user_name` |
| `camelCase` | `userName` |
| `PascalCase` | `UserName` |

## Сборка и запуск

### Требования

- Visual Studio Code 1.137 или новее;
- Node.js 18 или новее;
- npm.

### Установка зависимостей

```bash
npm install
```

### Компиляция

```bash
npm run compile
```

### Запуск расширения

Откройте проект в VS Code и нажмите `F5` или выберите **Run Extension**. Откроется отдельное окно Extension Development Host.

Команда расширения доступна через палитру команд под именем **Convert Styles** и имеет идентификатор `case-converter.convertStyles`.

### Создание и установка пакета VSIX

Для сборки расширения в установочный файл `.vsix` и его автоматической установки выполните в терминале следующие команды:

```bash
# 1. Сборка пакета (создаст файл case-converter-0.0.1.vsix)
npx @vscode/vsce package --allow-star-activation

# 2. Установка собранного расширения в VS Code
code --install-extension case-converter-0.0.1.vsix

## Основные модули

### `src/extension.ts`

Регистрирует команду расширения, получает активный документ и выделение, запрашивает Semantic Tokens, извлекает допустимые идентификаторы и выполняет единую транзакцию замен через `editor.edit`.

### `src/converter.ts`

Содержит функции преобразования и распознавания стилей:

- `convert` — преобразует имя в выбранный стиль;
- `detectStyle` — определяет стиль исходного имени;
- `extractVariables` — извлекает подходящие идентификаторы и их позиции;
- `NamingStyle`, `IdentifierType` и `VariableToken` — экспортируемые типы данных ядра.

## Ограничения

- Расширение зависит от языкового сервера, который должен предоставлять Semantic Tokens.
- Обрабатываются только идентификаторы, распознанные как `variable`, `parameter` или `property`.
